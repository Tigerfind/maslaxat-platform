# Правовая база AI

AI-чат использует локальный PostgreSQL full-text search по разрешённому корпусу нормативных документов. Массовый scraping `lex.uz` не выполняется.

## Почему нет автоматического копирования LexUZ

- `https://lex.uz/robots.txt` задаёт `Crawl-delay: 20`.
- Публичного документированного API полного корпуса не найдено.
- Условия предоставления информации ограничивают коммерческое копирование базы без письменного разрешения.
- RSS `https://lex.uz/ru/rss` подходит для обнаружения новых документов, но не предоставляет лицензированный полный текст.

Для production-корпуса необходимо получить письменное разрешение, API или лицензированную выгрузку у владельца LexUZ: `info@adolatmarkazi.uz`.

## Формат импорта

```json
{
  "title": "Название нормативного документа",
  "code": "Сокращение",
  "language": "ru",
  "sourceUrl": "https://lex.uz/ru/docs/ID",
  "version": "2026-01-01",
  "effectiveFrom": "2026-01-01",
  "isActive": true,
  "articles": [
    {
      "number": "22",
      "heading": "Название статьи",
      "text": "Разрешённый к использованию полный текст статьи..."
    }
  ]
}
```

Поддерживаются JSON с одним документом, массив JSON и JSONL.

```bash
cd backend/api
npm run db:migrate
npm run legal:import -- /absolute/path/corpus.json
```

Импорт принимает только URL с домена `lex.uz`, хранит каждую версию отдельно и транзакционно заменяет статьи конкретной версии.

## Поведение AI

- В запрос Claude передаются не более шести релевантных фрагментов.
- Фрагменты и пользовательские вложения помечаются как данные, а не инструкции.
- Подтверждённые утверждения цитируются маркерами `[S1]`, `[S2]`.
- API и история возвращают только реально процитированные источники.
- Если официального источника нет, AI обязан явно сообщить, что норма не проверена.
- При недоступном Claude возвращается безопасный fallback без статических ставок и неподтверждённых статей.
